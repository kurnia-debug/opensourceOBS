Materi OBS Studio (Bahasa Indonesia)

Situs statis berisi materi belajar OBS Studio: pengenalan, antarmuka interaktif, scene & source, audio, pengaturan streaming/recording, panduan per bab, kuis, dan catatan belajar.

Dibangun dari template gratis Tooplate 2170 Aperture (HTML + CSS + JavaScript murni, tanpa framework).

Struktur

index.html                    halaman utama (seluruh materi)
timer.html                    timer hitung mundur "Mulai Sebentar Lagi"
tooplate-2170-aperture.css    gaya tampilan
tooplate-2170-aperture.js     animasi, diagram interaktif, kuis, catatan
images/                       logo OBS, foto meja kerja, foto mikrofon
.nojekyll                     agar GitHub Pages menyajikan file apa adanya

Menjalankan lokal

Buka index.html di browser, atau:

python3 -m http.server 8000
# lalu buka http://localhost:8000

Upload ke GitHub & aktifkan GitHub Pages

  1. Buat repository baru di GitHub (mis. materi-obs).
  2. Dari folder ini: bash git init git add . git commit -m "Materi OBS Studio" git branch -M main git remote add origin https://github.com/USERNAME/materi-obs.git git push -u origin main
  3. Di GitHub: Settings → Pages → Build and deployment → Deploy from a branch, pilih branch main dan folder / (root), lalu Save.
  4. Situs aktif di https://USERNAME.github.io/materi-obs/ setelah beberapa menit.

Timer sebagai Browser Source di OBS

Tambahkan source Browser dan isi URL dengan timer.html?m=10&clean=1 (10 menit, tombol disembunyikan, langsung berjalan). Parameter: m = menit (1–180), clean=1 = sembunyikan kontrol dan mulai otomatis, auto=1 = mulai otomatis.

Catatan

  • Font memuat dari Google Fonts, jadi butuh internet untuk tampilan font yang tepat; tanpa itu otomatis memakai font cadangan.
  • Catatan belajar tersimpan di browser pengunjung (localStorage), bukan di server.
  • Angka rekomendasi bitrate/resolusi adalah titik awal umum; cek aturan terbaru platform Anda.
